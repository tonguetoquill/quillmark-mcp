# Bundled fonts — all OFL 1.1

- **Inter** (Variable + Italic Variable) — open-source neo-grotesque used as the body/heading fallback. https://github.com/rsms/inter

Real USAF decks commonly use Arial on Windows. Inter is bundled so the template renders consistently in hosted environments lacking Arial. If Arial is available system-side, Typst will prefer it via the font stack `("Arial", "Inter")`.
